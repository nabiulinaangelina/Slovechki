# Словечки

Android-приложение для повторения английских терминов из глоссария учебника и дополнительных карточек из переданных наборов. Всего в приложении 579 карточек: 481 термин глоссария и 98 дополнительных карточек. В тренировке показывается слово или перевод и несколько вариантов для сопоставления. Можно включать только нужные юниты, менять направление карточек и повторять набор по кругу. Слова и переводы хранятся в приложении, поэтому интернет для занятий не нужен.

## Сборка на GitHub

1. Создайте пустой репозиторий на GitHub.
2. Загрузите в него содержимое этой папки и отправьте коммит в ветку `main`.
3. Откройте вкладку **Actions**. Workflow `Android build` соберёт `app-debug.apk`.
4. Скачайте файл из артефакта `slovechki-debug-apk` в завершившемся запуске.

Workflow можно запустить вручную через **Actions → Android build → Run workflow**.

## Локальная сборка

Откройте папку в Android Studio либо выполните:

```bash
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Слова и переводы

- `app/src/main/assets/vocabulary.json` — 579 карточек, которые попадают в APK.
- `data/vocabulary.csv` — таблица для просмотра и ручной сверки.
- `data/translation_overrides.json` — уточнения переводов по определениям учебника; они сохраняются при повторном импорте карточек.
- `imports/unit-01.tsv` … `imports/unit-11.tsv` — исходные пары карточек, переданные для наполнения приложения.
- `tools/extract_glossary.py` извлекает термины и юниты из PDF.
- `tools/import_quizlet.py imports` сопоставляет карточки с терминами глоссария по номеру юнита, добавляет карточки из наборов, которых нет в глоссарии, и обновляет JSON и CSV.

Импорт переводов:

```bash
python3 tools/import_quizlet.py imports
```

Экспортированные файлы можно положить в `imports/`; в имени файла должен быть номер, например `unit-05.csv`. Поддерживаются CSV, TSV и TXT с двумя столбцами: термин и перевод. Дополнительные карточки сохраняются в соответствующем юните и тоже доступны в тренировке.

После добавления переводов в приложение автоматически включаются ответы для этих карточек. Домашний экран показывает, сколько переводов уже заполнено в каждом юните.
